---
title: <notehead> with parentheses
elements: notehead
description: This example demonstrates the rendering the &lt;notehead&gt; element with a parentheses attribute. The parentheses enclose any accidentals and augmentation dots along with the notehead. Rests are parenthesized using a &lt;level parentheses="yes"&gt; element instead, because rests don't have a notehead.
